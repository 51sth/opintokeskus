# Opintokeskus

Opintojen tehtävien, opetuspäivien ja kurssien päättymisten 14 päivän seurantasovellus.

## Käyttö

Sovellus julkaistaan GitHub Pagesissa osoitteessa https://51sth.github.io/opintokeskus/.

Tässä repositoriossa on vain sovelluksen yleinen käyttöliittymä. Omia opintotietoja ei ole julkaistu GitHubiin.

Avaa sivu ja valitse **Tuo omat tiedot** ladataksesi Opintokeskuksen henkilökohtaisen JSON-tiedoston. Voit merkitä tehtäviä tehdyiksi ja viedä varmuuskopion. Tiedot tallennetaan selaimen paikalliseen tallennustilaan.

**Älä lisää yksityistä opintotiedot-JSON-tiedostoa tähän julkiseen repositorioon.** Eri laitteiden välistä automaattista synkronointia ei ole.

## Päivitykset

Kun haluat muokata sovellusta, korvaa repositorion juuren `index.html`. GitHub Pagesin osoite ei muutu.

## GitHub Pages

Valitse repositorion **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Julkaisu voi kestää muutaman minuutin.
